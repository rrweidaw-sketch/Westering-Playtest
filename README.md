# Westering Playtest

Install once. Open the Westering Playtest shortcut before each session to get the latest build, then choose Play to host or Join Server to connect.

[Download the Windows installer](https://github.com/rrweidaw-sketch/Westering-Playtest/releases/latest/download/WesteringPlaytest-win-Setup.exe)

No GitHub account, Unity or Git is needed. This is an early Windows 64-bit prototype. The installer is not code-signed yet, so Windows may show an unknown-publisher warning.

## Join a friend

1. Install Tailscale for Windows and sign in: https://tailscale.com/download/windows
2. Accept the host's Tailscale machine-sharing invite.
3. Open Westering Playtest, wait for updates, then choose Play to host or Join Server to connect.
4. Ask the host for their Tailscale address, port and password.
5. Enter those details in the launcher and click Join Server. The address and port are remembered; the password is not saved. The default port is 7770.
6. Use the First test guide button in the launcher for the full test checklist.

Close the game before updating. Saves and player identity are stored outside the install folder. If an update fails, retry later or play the installed build.

This repository distributes installers and compiled game updates. The development repository is separate.
